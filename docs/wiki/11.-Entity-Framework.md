# 1. Entity Framework Core Integration

This document explains how to use Entity Framework Core with PL/.NET to perform database operations directly within PostgreSQL functions and procedures.

## 1.1. Overview

PL/.NET supports Entity Framework Core integration through external assembly loading, allowing you to use familiar ORM patterns within your PostgreSQL stored procedures and functions. This enables powerful data access scenarios while leveraging the full capabilities of Entity Framework Core with the Npgsql provider.

### 1.1.1. Key Features

- **Entity Framework Core Support**: Use DbContext, LINQ queries, change tracking, and all EF Core features
- **Npgsql Integration**: Built-in PostgreSQL provider support with optimized performance
- **Automatic Connection Management**: No connection string required - PL/.NET handles database connectivity
- **Model-First Development**: Define your entities and let EF Core handle the database mapping
- **LINQ Query Support**: Write complex queries using familiar LINQ syntax

### 1.1.2. Important Limitations

- **No Transaction Support**: PL/.NET currently doesn't support explicit transactions within Entity Framework operations. You must disable auto-transactions using `DbContext.Database.AutoTransactionsEnabled = false;`

## 1.2. Configuration

To use Entity Framework with external assemblies, you need to configure PL/.NET to load your compiled DLL containing the Entity Framework models and context.

### 1.2.1. Assembly Configuration Methods

PL/.NET provides two ways to specify external assemblies:

#### 1.2.1.1. Individual Assembly Paths
```sql
-- Set specific DLL paths (comma-separated)
SET pldotnet.user_assembly_paths = '/path/to/your/assembly1.dll,/path/to/your/assembly2.dll';
```

#### 1.2.1.2. Assembly Directory
```sql
-- Set a directory containing DLL files
SET pldotnet.user_assemblies_directory = '/path/to/your/assemblies/';
```

### 1.2.2. Configuration Example
```sql
-- Configure the path to your Entity Framework assembly
SET pldotnet.user_assembly_paths = '/app/pldotnet/tests/csharp/DotNetTestProject/bin/Release/CSharpTest.dll';
```

## 1.3. Creating Entity Framework Models

### 1.3.1. Entity Class Definition

Define your entity classes with appropriate data annotations:

```csharp
using System;
using System.ComponentModel.DataAnnotations;
using System.ComponentModel.DataAnnotations.Schema;

namespace EFCoreTest;

[Table("test_entity_framework", Schema = "public")]
public class TestEntityFramework
{
    [Key, Column("id")]
    public int Id { get; set; }

    [Column("name", TypeName = "varchar(100)")]
    public string Name { get; set; } = null!;

    [Column("category", TypeName = "varchar(100)")]
    public string Category { get; set; } = null!;

    [Column("price", TypeName = "money")]
    public decimal Price { get; set; }

    [Column("created_at", TypeName = "timestamp without time zone")]
    public DateTime CreatedAt { get; set; }

    [Column("is_active")]
    public bool IsActive { get; set; }
}
```

### 1.3.2. DbContext Definition

Create your DbContext with an empty connection string:

```csharp
using Microsoft.EntityFrameworkCore;

namespace EFCoreTest;

public class TestEntitiesContext : DbContext
{
    public DbSet<TestEntityFramework> TestEntities { get; set; } = null!;
    public DbSet<TestCategory> Categories { get; set; } = null!;

    protected override void OnConfiguring(DbContextOptionsBuilder options) =>
        options.UseNpgsql(""); // Empty connection string - PL/.NET provides the connection
}
```

## 1.5. Data Modification Operations

### 1.5.1. Important Notes for Write Operations

- **Always disable auto-transactions**: `DbContext.Database.AutoTransactionsEnabled = false;`
- **Use procedures for write operations**: Procedures are recommended for insert, update, and delete operations
- **Call SaveChanges()**: Don't forget to persist your changes

### 1.5.2. Delete Operations

#### 1.5.2.1. Single Delete
```sql
CREATE OR REPLACE PROCEDURE DeleteFirstEntity() AS $$
  using var ctx = new EFCoreTest.TestEntitiesContext();
  ctx.Database.AutoTransactionsEnabled = false;
  var first = ctx.TestEntities.OrderBy(e => e.Id).FirstOrDefault();
  if (first != null)
  {
      ctx.TestEntities.Remove(first);
      ctx.SaveChanges();
  }
$$ LANGUAGE plcsharp;
```

#### 1.5.2.2. Bulk Delete
```sql
CREATE OR REPLACE PROCEDURE DeleteEntitiesByIds(ids INT[]) AS $$
  using var ctx = new EFCoreTest.TestEntitiesContext();
  ctx.Database.AutoTransactionsEnabled = false;
  var toDelete = ctx.TestEntities.Where(e => ids.Cast<int>().ToArray().Contains(e.Id)).ToList();
  if (toDelete.Count > 0)
  {
      ctx.TestEntities.RemoveRange(toDelete);
      ctx.SaveChanges();
  }
$$ LANGUAGE plcsharp;
```

### 1.5.3. Update Operations

#### 1.5.3.1. Single Update
```sql
CREATE OR REPLACE PROCEDURE UpdateEntityName(id INT, new_name TEXT) AS $$
  using var ctx = new EFCoreTest.TestEntitiesContext();
  ctx.Database.AutoTransactionsEnabled = false;
  var entity = ctx.TestEntities.SingleOrDefault(e => e.Id == id);
  if (entity == null) return;
  entity.Name = new_name;
  ctx.SaveChanges();
$$ LANGUAGE plcsharp;
```

#### 1.5.3.2. Bulk Update
```sql
CREATE OR REPLACE PROCEDURE DoublePriceByCategories(categories TEXT[]) AS $$
  using var ctx = new EFCoreTest.TestEntitiesContext();
  ctx.Database.AutoTransactionsEnabled = false;
  var toUpdate = ctx.TestEntities.Where(e => categories.Cast<string>().ToArray().Contains(e.Category)).ToList();
  foreach (var e in toUpdate)
      e.Price *= 2;
  if (toUpdate.Count > 0)
      ctx.SaveChanges();
$$ LANGUAGE plcsharp;
```

### 1.5.4. Insert Operations

#### 1.5.4.1. Single Insert
```sql
CREATE OR REPLACE PROCEDURE InsertEntity(name TEXT, category TEXT, price MONEY, created_at TIMESTAMP, is_active BOOLEAN) AS $$
  using var ctx = new EFCoreTest.TestEntitiesContext();
  ctx.Database.AutoTransactionsEnabled = false;
  var ent = new EFCoreTest.TestEntityFramework
  {
      Name = name,
      Category = category,
      Price = price ?? 0m,
      CreatedAt = created_at ?? DateTime.Now,
      IsActive = is_active ?? false
  };
  ctx.TestEntities.Add(ent);
  ctx.SaveChanges();
$$ LANGUAGE plcsharp;
```

#### 1.5.4.2. Bulk Insert
```sql
CREATE OR REPLACE PROCEDURE InsertEntitiesRange(
  names_array TEXT[], categories_array TEXT[], prices_array MONEY[], created_at_array TIMESTAMP[], is_active_array BOOLEAN[]
) AS $$
  var names = names_array.Cast<string>().ToArray();
  var categories = categories_array.Cast<string>().ToArray();
  var prices = prices_array.Cast<decimal?>().Select(p => p ?? 0m).ToArray();
  var createdAts = created_at_array.Cast<DateTime?>().Select(d => d ?? DateTime.Now).ToArray();
  var isActives = is_active_array.Cast<bool?>().Select(b => b ?? false).ToArray();
  var list = new List<EFCoreTest.TestEntityFramework>();
  for (int i = 0; i < names.Length; i++)
  {
      list.Add(new EFCoreTest.TestEntityFramework {
          Name      = names[i],
          Category  = categories[i],
          Price     = prices[i],
          CreatedAt = createdAts[i],
          IsActive  = isActives[i]
      });
  }
  using var ctx = new EFCoreTest.TestEntitiesContext();
  ctx.Database.AutoTransactionsEnabled = false;
  ctx.TestEntities.AddRange(list);
  ctx.SaveChanges();
$$ LANGUAGE plcsharp;
```
